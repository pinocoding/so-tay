## Claude Code とは？

Claude Code は Anthropic の **エージェント型コーディングツール** です。やりたいことを自然な言葉で伝えると、Claude がコードベースを読み、ファイルを編集し、コマンドを実行し、結果を自分で確認します。ターミナルから始まり、現在はエディタ、デスクトップアプリ、Web、スマートフォンでも使えます。

**GitHub Copilot**（入力中に出る候補）や **Tabnine** などのコード補完ツールとの大きな違いは、補完ツールが **次の数行** を予測して提案するだけなのに対し、Claude Code は **タスク全体** を最初から最後までこなすことです。

例：ログインページに「パスワードを忘れた」ボタンを追加したいとき

- **コード補完ツール：** どのファイルを直すかを自分で判断し、自分で入力していく。ツールは途中で数行を提案するだけ。
- **Claude Code：** 「ログインページに『パスワードを忘れた』ボタンを追加して」と伝えるだけ。Claude が対象のファイルを探し、ボタンを追加し、パスワード再設定ページを作り、エラーがないか動かして確認する。

実際の操作：プロジェクトのフォルダでターミナルを開き、次のように入力します。

```bash
cd my-project     # プロジェクトのフォルダに移動
claude            # Claude Code を起動
> ログインページに「パスワードを忘れた」ボタンを追加して
```

完了すると、Claude が何をしたかを報告します。例：

```text
✓ ログインページを発見: src/pages/login.tsx
✓ 「パスワードを忘れた」ボタンを追加
✓ 新しいページを作成: src/pages/forgot-password.tsx
✓ 試運転: エラーなし
```

- 公式概要: [code.claude.com/docs/en/overview](https://code.claude.com/docs/en/overview)

## バイブコーディングとは？

**バイブコーディング（Vibe Coding）** とは、コードを 1 行ずつ書く代わりに、欲しい結果（「ダークモード付きの ToDo アプリを作って」）を説明し、AI にコードの大部分を書かせる開発スタイルです。Andrej Karpathy 氏が名付けました。

| 向いていること | 注意点 |
| --- | --- |
| プロトタイプ、デモ、個人用ツール | 読んでいないコードにはバグやセキュリティ問題が隠れることがある |
| 新しいフレームワークを素早く学ぶ | 大きなプロジェクトは構造がないと崩れやすい |
| ゼロから「動く」状態まで速く進む | 本番コードにはレビューとテストが必要 |

<Callout title="ヒント">
バイブコーディングは出発点です。実際のプロジェクトでは Plan モード、テスト、コードレビューと組み合わせましょう。
</Callout>

## コーディングエージェントとは？

**コーディングエージェント** は、質問に答えるだけでなく、**あなたの代わりに実際の作業をする** AI です（ファイルを開く、コードを書き換える、プログラムを動かす）。**ツール**（ファイルの読み書き、シェルコマンドの実行、Web 検索など）を持ち、タスクが終わるまで次にどのツールを使うかを自分で判断します。

| チャットアシスタント | コーディングエージェント |
| --- | --- |
| あなたがコードを貼り付け、AI が答える | AI が自分でファイルを読む |
| あなたが回答をコピーして戻す | AI が直接ファイルを編集する |
| あなたがテストを実行する | AI がテストを実行し、失敗に対応する |

## エージェントループとは？

Claude Code のすべてのタスクは、次のようなループで進みます：

**情報収集 → 計画 → 実行 → 検証** を、目標を達成するまで繰り返します。

**車の整備士** を想像してください：車を見る → 壊れた所を見つける → 直す → 試運転する。試運転でうまくいかなければ、もう一度見直します。

![Claude は車の整備士のように動きます：車を見る（情報収集）、壊れた所を見つける（計画）、直す（実行）、試運転する（検証）。うまくいかなければ繰り返す](/images/claude-code/agentic-loop.svg)

**実際の例：** Claude に「Web サイトの登録ボタンが押せません。直してください」と頼んだ場合

1. **情報収集**：登録ボタンに関係するファイルを読み、仕組みを理解する。
2. **計画**：ボタンが押せない原因を見つけ、直し方を決める。
3. **実行**：ファイルを修正する。
4. **検証**：ページを試す。**まだ** 押せなければ手順 1 に戻って調べ直す。押せる **ようになれば**「修正しました」と報告する。

<Callout title="ヒント">
`Esc` でいつでもループを止めて、別の方向へ導けます。
</Callout>

## サブスクリプション

**Claude のサブスクリプション** があれば、Claude Code の利用はプランに含まれます。

| プラン | 対象 |
| --- | --- |
| Pro | 個人、日常的な利用 |
| Max | ヘビーな個人利用、より高い上限 |
| Team | 小規模チーム、管理と請求をまとめて |
| Enterprise | 組織向け：SSO、監査ログ、管理機能 |

セッション内で残りの利用量を確認するには `/usage` を使います。

## API 利用

### 仕組み

API を使う場合、月額料金は払いません。代わりに、使った **トークン** の量に応じて支払います。

- **入力トークン:** Claude に送るすべてのもの。コマンド、コード、Claude が読んだファイルの内容を含みます。
- **出力トークン:** Claude の回答と、Claude が生成する操作。

料金はモデルによって異なり、通常は 100 万トークンあたりで計算されます。多くのファイルを読む、何度もループを回す、長い作業をするといった場合は、単純な質問 1 回よりトークンを多く使います。

### 接続方法

Claude Code に API を使わせるには、API キーを環境変数 `ANTHROPIC_API_KEY` に設定します。この環境変数があると、Claude Code はプランのログインではなくこのキーを使います。

```bash
export ANTHROPIC_API_KEY="sk-ant-..."
claude
```

<Callout type="warn">
API キーを Git にコミットしないでください。環境変数やシークレット管理ツールに保存しましょう。
</Callout>

### 無料プラン・前払いとの比較

| 項目 | 無料プラン | 月額プラン（Pro, Max） | API 前払い（クレジット購入） |
| --- | --- | --- | --- |
| Claude Code の利用 | 不可 | 可 | 可 |
| 支払い方法 | 無料 | 毎月の定額 | 先にクレジットを購入し、使った分を差し引く |
| 制限 | 非常に少ない | 5 時間セッションと週ごとの上限あり | セッションごとの上限なし。残高とアカウントのレート制限のみ |
| 費用 | なし | 予測しやすい | 使用量によって変動 |
| 上限に達したとき | 待つ | リセットを待つ、またはプランを上げる | 残高がなくなると停止（自動チャージを有効にしていなければ） |
| 向いている用途 | チャットを試す | 毎日の利用 | 自動化、システムへの統合、不定期の利用 |

### API を使うのに向いている場合

API は、Claude Code が **人が待っていない状態で** 動くときに使います。つまり、自動的に起動され、誰もコマンドを打って結果を待たない場合です。代表的な例を挙げます。

**プルリクエストのたびに自動でコードレビューする。** チームは GitHub を使っています。誰かがプルリクエストを開くたびに、システムは自動で次の作業を行います。

1. 変更されたばかりのコードを取得する。
2. Claude Code に送って確認させる。
3. 結果（考えられるバグ、修正案）をプルリクエストのページに投稿する。

誰も何も操作しません。作成者が戻ってきたときには、レビューがすでに付いています。設定例は次のとおりです。

```yaml
# .github/workflows/review.yml
name: Review pull request
on: pull_request

jobs:
  review:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - run: npm install -g @anthropic-ai/claude-code
      - run: claude -p "main ブランチとの差分を確認し、考えられるバグを挙げて"
        env:
          ANTHROPIC_API_KEY: ${{ secrets.ANTHROPIC_API_KEY }}
```

- `claude -p` は Claude Code を 1 回実行して終了します。入力を待つ画面は開きません。
- `${{ secrets.ANTHROPIC_API_KEY }}` はリポジトリのシークレットからキーを読み込みます。キーがコードに現れることはありません。

ほかの場面も同じ仕組みです。ログからエラーを毎朝まとめるレポートや、元のファイルが変わったときの自動ドキュメント更新などが該当します。

**自動化には前払いの API を選びます。** システムは継続的に動くため、残高を常に確保しておく必要があります。Pro と Max は直接作業する人向けで、自動実行には使いません。

### API を使わないほうがよい場合

- 毎日 Claude Code を **継続的に使って** 作業している場合。Pro や Max のほうが費用を予測しやすいことが多いです。
- 使い始めたばかりの場合。サブスクリプションのほうが始めやすく、予想外の出費のリスクも少なくなります。

### API 利用時の注意点

- **初期設定では支出の上限がありません。** 使い始める前に Claude Console で支出上限を設定してください。
- **残高を切らさないようにします。** クレジットがなくなると、自動実行は失敗しても誰もすぐには気づけません。自動チャージを有効にするか、残高が少なくなったら通知されるようにしておきましょう。
- **費用を確認します。** Console で使用量を確認し、どの作業がトークンを多く使っているかを把握してください。
- **料金は変わることがあります。** 最新の料金は [claude.com/pricing](https://claude.com/pricing) で確認してください。
