## What is Mendix?

Mendix is a **low-code** platform from Siemens. Instead of writing all the code, you build applications with visual tools by dragging and dropping ready-made components.

## Main building blocks

- **Studio Pro:** the desktop app used to design and run Mendix applications.
- **Domain Model:** the data model that describes entities and the relationships between them.
- **Pages:** the user interface.
- **Microflows:** the logic, for example validating data or saving records.
